# Yjs correctness evidence ledger

This ledger records the counterexample before each fix, the production rule
that closes it, and the recovery boundary when the operation cannot safely be
continued. A browser test is refinement evidence across JavaScript/Wasm/KiCad;
it is not substituted for the smaller app-free regression.

The server is deliberately absent from every conflict-policy row. It never
compares valid native documents or chooses their winner; Yjs does. Production
admits one schema, restores/persists Yjs state, serves validated reads and
records report-only lint evidence. It has no room-apply or checkpoint-revert
entrypoint. `.ydoc.good` is forensic only. Repair is an authenticated Yjs
protocol update followed by explicit native reload.

## Baseline and current audit status

The earlier `2026-08-22` green snapshot (303 shared, 409 standalone, 43 sync,
72 Dafny obligations and 23 browser/Wasm cases) predates this expanded drift
audit and must not be used as evidence for the new fixes.

The expanded 186-case collaboration baseline produced 162 passes, 17 failures
and 7 skips; both load-fuzz cases failed. Sixteen failures were a schematic
library normalization/coverage defect and one was a PCB pre-ACK undo ordering
case. Those failures, plus reconnect loss, omitted PCB roots, stale save,
online compaction and a real footprint's board-owned references, became focused
red/green regressions rather than being hidden as expected failures.

At this ledger update the completed focused gates include 313/313 shared tests,
422/422 standalone tests through the library-coverage slice, 11/11 gateway
reconnect tests, the two real PCB root canaries, and 99 Dafny obligations with
zero errors. The save-cut classifier has 8/8 app-independent cases. The real
corpus discovery run had four green documents and one StickHub failure before
the component-class ownership repair. The authoritative final handoff must
record a fresh full collaboration matrix, both fuzz cases, the post-repair real
corpus and the real save/recreate cases; focused green results are not a substitute
for that gate.

evidence, not the same spec preserved at the production-red commit.
