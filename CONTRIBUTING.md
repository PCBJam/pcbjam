# Contributing to PCBJam

Thanks for your interest in PCBJam. We don't accept pull requests or code from
outside the team; we write all the code ourselves. You can still help a lot:

- **Found a bug?** Open an [issue](https://github.com/PCBJam/pcbjam/issues) here,
  or post it in the `#bug-reports` forum on our
  [Discord](https://discord.gg/ybhqJxjR3E). Say which browser you used and how
  to reproduce it. Screenshots help.
- **Have an idea or feedback?** Open an issue, or post it in `#feedback` on the
  same Discord.
- **Found a security problem?** Don't post it in an issue, on Discord or
  anywhere else public. Use
  **Report a vulnerability** under this repo's **Security** tab, or email
  [hello@pcbjam.com](mailto:hello@pcbjam.com).

If the bug also happens in desktop KiCad, report it to
[KiCad](https://gitlab.com/kicad/code/kicad/-/issues) instead.
